# IRONFORGE FITNESS

Premium cinematic gym landing page inspired by the `lets-scroll` scroll-scrub storytelling concept.

## Structure
- `index.html` — semantic page structure and content sections
- `styles.css` — responsive visual system, cinematic scenes, glass panels and reduced-motion rules
- `app.js` — content data, GSAP/ScrollTrigger motion, navigation and form behavior

## Experience
The six main scenes are presented as one connected vertical journey. GSAP/ScrollTrigger drives camera-like depth, scale and parallax changes from scroll position. The visual backgrounds are CSS-composed placeholders so the project runs immediately without a paid image/video generation pipeline; they can be replaced by pre-rendered scene stills/video assets following the `lets-scroll` seam-locked chain described by the source skill.

## Run
Open `index.html` directly or serve the folder with any static web server.
